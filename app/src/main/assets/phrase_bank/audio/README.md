# Santali Phrase-Bank Audio Directory

Place natural human-recorded Santali audio files for classroom phrases in this directory.

## Requirements:
- **Format:** OGG with Opus codec (or AAC/MP3 fallback)
- **Sample rate:** 16kHz mono (optimized for voice playback & small storage footprint)
- **Naming convention:** Matches the `audio_file` path specified in `phrase_bank.json` (e.g., `pb_0001.ogg`, `pb_0002.ogg`, etc.).
- **Source:** Pre-recorded native Santali speakers or IndicVoices-R dataset clips. No synthetic or generated audio clips.
